<h1>Медиа-каталог</h1>
<p>Media Catalog — личная картотека фильмов/сериалов/книг/манхвы: добавляйте находки “на потом”, отмечайте статусы (в планах/в процессе/завершено/брошено), ставьте оценку и оставляйте отзывы. Проект помогает держать список “что посмотреть/почитать” аккуратным и находить нужное через поиск и фильтры.</p>

<ul><li>[ ] Регистрация/Вход/Выход</li><li>[ ] Элементы глобального каталога</li><li>[ ] Профиль пользователя и личная библиотека</li><li>[ ] Добавление/удаление элемент в личной библиотеке</li><li>[ ] Статусы (запланировано/в процессе/завершено/брошено)</li><li>[ ] Редактирование записи в личной библиотеке (статус, оценка, отзыв)</li><li>[ ] Поиск по названию</li><li>[ ] Фильтры по типу, статусу</li><li>[ ] Глобальные отзывы и рейтинг</li></ul>
